# 용어집 (Glossary)
> 역할: 문서/데이터/코드/UI에서 사용하는 용어를 단일 기준으로 통일한다.

- 마지막 갱신: `2026-02-21`

## 사용 규칙

- 전장의 배치 제한(Slot Limit)은 **기본적으로 없음(무제한)** 이며,
  전장 데이터에 제한이 **명시된 경우에만** 적용한다.

- 이 문서의 **한글/영문 표기**를 “정식 용어(Canonical)”로 사용한다.
- 동일 개념에 대해 문서에서 다른 표현을 쓰지 않는다.
  - 예: `전투력 4`(혼용 위험) 같은 표기는 금지. 대신 **`Power 4 (d4)`** 또는 문장으로 **`Power=4`**라고 쓴다.
- 합산값은 **Combat Strength**로만 부른다.
  - 예: “전장 Combat Strength” / “전장별 Combat Strength”
- 카드 타입은 `Squad`, `Support` 두 가지로 통일한다.
  - `부대 카드`, `지원 카드` 같은 표현은 문서/데이터에서 금지(별칭으로만 언급).
- “덱”은 드로우/핸드가 없는 **편성 리스트**를 의미하며, 문서에서는 **덱(편성)** 또는 **Roster Deck**로 표기한다.

## 주사위 표기 규칙 (확정)

- **Power**: 병력의 주사위 면수. `Power X`는 `dX`를 의미한다.
  - 예: `Power 4` = `d4`
- **눈(Face Value)**: 굴림 결과 값.
- **핵심 원칙(확정)**: 효과 텍스트에서 별도 명시가 없다면, 모든 “수치 증가/감소”는 **눈(Face Value) 변화**를 의미한다.
  - 예: `모든 아군 눈 +1`
- **시각적 피드백(권장 규칙)**: 조건부 효과가 발동된 상태라면, 플레이어가 즉시 알 수 있도록 **최종 눈**이 UI에 반영되어야 한다.
  - 툴팁에는 “기본 굴림값 → 보정 내역 → 최종값” 로그가 보이는 것을 권장.
- **최솟값(확정)**: 눈의 최솟값은 `1`
- **최댓값(확정)**: 눈의 최댓값은 **없음(상한 없음)**  
  - 즉, `Power 4`라도 효과에 의해 눈이 `5, 6...`처럼 커질 수 있다.

## 핵심 용어(한글/영문) 확정표

| 카테고리 | 한글(확정) | 영문(확정) | 설명 | 비고 / 금지(혼용 방지) |
|---|---|---|---|---|
| 진행 | 런 | Run | 게임 오버까지의 1회 플레이 | |
| 진행 | 전투 | Battle | 하나의 적 조우(전투 단위) | `전장`과 혼동 금지 |
| 진행 | 게임 오버 | Game Over | 런이 즉시 종료되는 상태 | 조건: **전투 패배(플레이어 Morale ≤ 0)** |
| 진행 | 턴 | Turn | 전투 내 반복되는 단위 | |
| 진행 | 단계 | Phase | 턴을 구성하는 하위 절차 | |
| 리소스 | 사기 | Morale | 전투에서의 체력(0 이하면 전투 종료) | `체력`은 설명용 보조로만 |
| 리소스 | 안정도 | Stability | 후퇴(Retreat)에 사용하는 런 단위 자원 | 0 이하이면 후퇴 불가(게임 오버 조건 아님) / 최소 0으로 clamp |
| 리소스 | 보급품 한도 | Supply Limit | 한 전투에 편성 가능한 총 보급품 상한 | `보급품` 단독 표기 지양 |
| 리소스 | 보급품 비용 | Supply Cost | 카드가 차지하는 보급품 비용 | (오타) `보금품` 금지 |
| 리소스 | 마나(최대 5) | Mana | 스킬 사용 자원(전투 시작 시 최대치로 충전) | 턴 회복 2 |
| 시스템 | 덱(편성) | Roster Deck | 전투에 들고 들어가는 카드 편성 리스트 | **드로우/핸드 없음** |
| 시스템 | 예비 편성 | Reserves | 편성 덱에 넣지 않은 카드를 보관하는 공간(구 벤치) | `벤치` 금지 |
| 시스템 | 진영 | Camp | 아군 병력들이 대기하는 장소(전장 배치의 출발점) | |
| 카드 | Squad | Squad | 전투 시작 트리거로 병력을 소환/준비시키는 카드 타입 | `부대 카드` 금지 |
| 카드 | Support | Support | 전투 시작 트리거로 버프/규칙 수정 등을 주는 카드 타입 | `지원 카드` 금지 |
| 유닛 | 병력 | Troop | 전장에 배치 가능한 주사위 유닛(개체) | |
| 유닛 | 병력 주사위 | Troop Die | 병력의 주사위(파워/눈/효과 포함) | |
| 주사위 | Power | Power | 병력의 `Power X (=dX)` | `면수`, `주사위 dX`만 단독 사용 지양 |
| 주사위 | 눈 | Face Value | 굴림 결과 값(최소 1, 상한 없음) | |
| 전장 | 전장 | Battlefield | 병력을 배치해 승패를 가르는 슬롯/지형 | |
| 전장 | 전장 배치 제한 | Slot Limit | 전장에 놓을 수 있는 병력 수 제한(기본: 제한 없음, 명시된 경우만 적용) | |
| 전장 | 전장 Combat Strength | Combat Strength | 해당 전장에 배치된 병력들의 최종 눈 합(+전장/스킬 보정) | `Battlefield Power` 금지 |
| 정보 | 적 의도 | Enemy Intent | 적의 배치 계획/행동이 플레이어에게 공개되는 정보 | 프로토타입: 완전 공개 |
| 판정 | 승리 | Victory | Combat Strength 비교 결과 이김 | |
| 판정 | 대승리 | Great Victory | 승리이면서 `승자 >= 패자 * 2` | 구 `Crushing Victory` 금지 |
| 판정 | 무승부 | Draw | Combat Strength 동률 | |
| 판정 | 패배 | Defeat | Combat Strength 비교 결과 짐 | |
| 판정 | 대패 | Great Defeat | 패배이면서 `패자 * 2 <= 승자` | 용어는 추후 변경 가능 |
| 행동 | 후퇴 | Retreat | 배치 단계에서 전투 이탈(보상 없음, Stability -1) | **Stability > 0일 때만 가능** / 보스전 불가 |
| 행동 | 재배치 | Redeploy | 아군 병력 1개를 다른 전장으로 이동(스킬) | 굴림 후 이동 시 **눈 유지** |

## 전투 단계(한글/영문) 표준 이름

> 주의: 메타의 "정비 단계"와 전투의 "정리 단계"가 혼동되기 쉬움.
> 문서에서는 전투 내 "정리 단계"를 **"회수 단계"**로 표기한다.

| 범위 | 한글(확정) | 영문(확정) | 설명 |
|---|---|---|---|
| 메타 | 보상 단계 | Reward Phase | 전투 종료 후 카드/골드 등 보상을 획득 |
| 메타 | 정비 단계 | Maintenance Phase | 보급품 한도에 맞춰 덱(편성) 구성/교체(예비 편성 포함) |
| 전투 시작(1회) | 전투 시작 트리거 | Battle Start Triggers | 편성 덱의 모든 카드가 1회 트리거(우선순위: Squad → Support) |
| 턴 | 회수 단계(=구 정리 단계) | Recall Phase | 배치된 모든 병력이 진영으로 복귀(프로토타입: 전장 고정) |
| 턴 | 적 배치 단계(=구 적 단계) | Enemy Deploy Phase | 적이 의도에 따라 전장에 병력 배치(의도 공개) |
| 턴 | 아군 배치 단계(=구 배치 단계) | Player Deploy Phase | 플레이어가 진영 병력을 전장들에 분배해 배치(후퇴 가능) |
| 턴 | 굴림 단계 | Roll Phase | 양측 병력 주사위 굴림 및 전장 Combat Strength 계산 |
| 턴 | 조정 단계 | Tactics Phase | 스킬/이동/보정으로 눈/배치/규칙을 조정(시각적 피드백 중요) |
| 턴 | 판정 단계(=구 확정 단계) | Resolve Phase | 전장별 결과(대승/승/무/패/대패) 확정 및 전장 효과/피해 적용 |

## 데이터/코드 키 권장 매핑 (camelCase)

> 목적: 문서 용어(한글) ↔ 구현/데이터(영문)를 1:1로 연결해 혼용을 방지한다.

| 한글 용어 | 영문 키(권장) | 타입 예시 | 비고 |
|---|---|---|---|
| 사기(현재/최대) | morale / moraleMax | int | 전투 HP |
| 안정도(현재/최대) | stability / stabilityMax | int | 후퇴에 쓰는 런 자원(0 이하면 후퇴 불가) |
| 보급품 한도 | supplyLimit | int | 편성 상한 |
| 보급품 비용 | supplyCost | int | 카드 비용 |
| 마나(현재/최대) | mana / manaMax | int | 전투 시작 시 mana=manaMax (=5) |
| 턴 회복 마나 | manaRegenPerTurn | int | 기본 2 |
| 쿨다운(턴) | cooldownTurns | int | 턴 종료 시 -1 |
| 병력 Power | power | int | `Power 4` → power=4 |
| 병력 눈(굴림값) | faceValue | int | 최소 1, 상한 없음 |
| 눈 보정(+/-) | faceBonus | int | 기본 0 |
| 눈 배수(×K) | faceMultiplier | int | 기본 1 |
| 전장 배치 제한 | slotLimit | int | |
| 전장 Combat Strength | combatStrength | int | 최종 합(+전장/스킬 보정 포함) |
| 전장 결과 | outcome | enum | greatVictory/victory/draw/defeat/greatDefeat |
| 카드 타입 | cardType | enum | squad/support |
