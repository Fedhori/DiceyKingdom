## 3) 강화(아이디어)

- Squad 내부 Troop들의 Face Value +1
- 선택한 Troop 1개의 Face Value +2
- Squad의 Supply Cost -1

> 참고: P0에서는 Power 변경 금지. 강화 시스템은 P0 범위 밖.
