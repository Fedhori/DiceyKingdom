# 백로그 (비정본)

**역할(Role):** 승인되지 않은 아이디어와 러프 노트를 기록하는 문서.

**최종 수정일(Last updated):** 2026-02-25

## 사용 규칙

- 이 파일은 비정본 아이디어 기록용 문서다.
- 이 파일의 모든 신규/수정 항목은 한글로 작성한다.

## 아이디어 메모

### 시각 효과 / 사운드 효과

- 시각 효과:
  - 체력 손실 시 혈흔 분출
  - 지속형 혈흔 데칼
- 사운드 효과:
  - 피격 사운드
  - 무기 충돌 사운드
  - 관중 반응 사운드

### 서사 / 보스 아이디어

- 최종 보스: 황제 아키타입
- 멘토 역할 인물이 후반에 황제 측으로 드러나는 전개

### 전장/결투 규칙 아이디어 (백로그)

- 전장에 랜덤 모디파이어 부여:
  - 이긴 쪽 피해 `+1`
  - 전장당 모디파이어 `1개만 허용`
- 방패 올리기:
  - 플레이어가 승리 시 무승부로 처리

### 패시브 아이디어

- 손수건:
  - 설명: 전장으로 떠나던 날, 그녀가 준 것입니다.
  - 효과: 체력 `+2`
- 반사신경:
  - 아무 능력도 배치하지 않은 전장에 총 파워 `+5`
- 모멘텀:
  - 전장에서 승리할 경우, 이번 결투 동안 해당 전장의 총 파워 `+2`
- 마지막 한방:
  - 체력이 `0` 이하로 떨어져도 이번 턴 결투에서 승리하면 체력 `1`로 생존
- 압도:
  - 한 턴에 세 전장에서 모두 이기면 모든 전장에 `+2` 보너스
- 명예로움:
  - 항복 불가능
  - 용량(CAP) `+2`

### 어빌리티 아이디어

- 흘려내기:
  - 적의 선택한 능력 하나를 `1턴 비활성화`
  - 쿨다운 길게 설계 (남용 방지)
- 숙련된 재장전:
  - 자신을 제외한 모든 능력의 쿨다운 `-1`
  - 쿨다운 `2`
- 흑요석 칼:
  - 비용 `1`, 파워 `12`
  - 사용할 때마다 파워 `-2`
- 복수심:
  - 비용 `2`, 파워 `5`
  - 패배할 때마다 파워가 `2배`
- 언더독:
  - 비용 `2`, 파워 `10`
  - 전장에 상대방 능력이 더 많으면 파워 `100%` 증가
- 난타:
  - 비용 `1`, 파워 `5`
  - 전장에 플레이어 능력이 더 많으면 파워 `+5`
- 외로운 늑대:
  - 비용 `2`, 파워 `24`
  - 해당 능력만 단독 배치 가능
- 모래 뿌리기
  - 비용 '1', 스킬
  - 선택한 전장의 모든 적 능력 파워 -4
- 거대 망치
  - 비용 '3' 파워 '20'
  - 승리 시, 전장의 무작위 상대 능력 하나의 쿨다운 +1
- 현혹
  - 1턴동안 상대 능력이 내꺼가 됨 (엄청 강력하니, 주의 필요)
- 단검 난사
  - 결투 시작 시, 해당 능력의 복제본을 2개 얻습니다.
  - 비용 2, 파워 5

### 메타/진행 시스템 아이디어

- 제약 시스템:
  - 결투 시작 전 디버프를 받는 대신 보상 제공
- 경험치/레벨업:
  - 레벨업 보상으로 용량 증가 + 패시브 획득

### 전투 UI 기술 백로그

- 16:9 다중 해상도 대응:
  - 목표: `DuelScreen` 레이아웃이 16:9 전 해상도 구간에서 클리핑/겹침 없이 유지되도록 앵커/스케일 정책 정리
  - 범위: 이번 프로토타입 개선 작업에는 포함하지 않음
