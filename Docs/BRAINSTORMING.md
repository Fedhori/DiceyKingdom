## Talent 시스템 (초안)

- 목표: 기존 Ability `Passive` 타입을 제거하고, 상시/조건부 효과를 `Talent`라는 별도 시스템으로 분리한다.
- 공통 원칙:
  - Talent는 Ability와 별도 데이터/런타임 구조로 관리한다.
  - 플레이어/적 모두 Talent를 여러 개 가질 수 있다.
  - 개념 참조: 슬더스 유물, 더 바자르 스킬처럼 전투 전반에 영향을 주는 장치.
- 범위 메모:
  - 이번 작업에서는 Talent 구현을 하지 않는다.
  - 이번 작업의 목적은 Passive 관련 기존 로직 정리 + Talent 명명 고정이다.
