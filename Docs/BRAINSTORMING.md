## 아이디어 메모

## Talent 시스템 (초안)

- 목표: 기존 Ability `Passive` 타입을 제거하고, 상시/조건부 효과를 `Talent`라는 별도 시스템으로 분리한다.
- 공통 원칙:
  - Talent는 Ability와 별도 데이터/런타임 구조로 관리한다.
  - 플레이어/적 모두 Talent를 여러 개 가질 수 있다.
  - 개념 참조: 슬더스 유물, 더 바자르 스킬처럼 전투 전반에 영향을 주는 장치.
- 범위 메모:
  - 이번 작업에서는 Talent 구현을 하지 않는다.
  - 이번 작업의 목적은 Passive 관련 기존 로직 정리 + Talent 명명 고정이다.

## 아이디어 분류 메모 (2026-02-25)

### 전장/결투 규칙 아이디어 (BACKLOG)

- 전장에 랜덤 모디파이어 부여:
  - 이긴 쪽 피해 `+1`
  - 전장당 모디파이어 `1개만 허용`
- 방패 올리기:
  - 플레이어가 승리 시 무승부로 처리

### Talent 아이디어

- 손수건:
  - 설명: 전장으로 떠나던 날, 그녀가 준 것입니다.
  - 효과: 체력 `+2`
- 반사신경:
  - 아무 능력도 배치하지 않은 전장에 총 파워 `+5`
- 모멘텀:
  - 전장에서 승리할 경우, 이번 결투 동안 해당 전장의 총 파워 `+2`
- 마지막 한방:
  - 체력이 `0` 이하로 떨어져도 이번 턴 결투에서 승리하면 체력 `1`로 생존
- 압도:
  - 한 턴에 세 전장에서 모두 이기면 모든 전장에 `+2` 보너스
- 명예로움:
  - 항복 불가능
  - CAP `+2`

### Ability 아이디어

- 흘려내기:
  - 적의 선택한 능력 하나를 `1턴 비활성화`
  - 쿨다운 길게 설계 (남용 방지)
- 대형 쇠뇌:
  - 피해 높음
  - 쿨다운 `2턴`
- 검과 방패:
  - 최소값이 피해의 절반
- 숙련된 재장전:
  - 자신을 제외한 모든 능력의 쿨다운 `-1`
  - 쿨다운 `2`
- 광란:
  - 이번 결투에서 받은 피해 `1`당 파워 `+3`
- 자만심:
  - 비용 `1`, 파워 `12`
  - 패배할 경우 이번 결투에서 제거
- 흑요석 칼 (안 A):
  - 상세 미정
- 흑요석 칼 (안 B):
  - 비용 `1`, 파워 `12`
  - 사용할 때마다 파워 `-2`
- 복수심:
  - 비용 `2`, 파워 `5`
  - 패배할 때마다 파워가 `2배`
- 언더독:
  - 비용 `2`, 파워 `10`
  - 전장에 상대방 능력이 더 많으면 파워 `100%` 증가
- 난타:
  - 비용 `1`, 파워 `5`
  - 전장에 플레이어 능력이 더 많으면 파워 `+5`
- 외로운 늑대:
  - 비용 `2`, 파워 `24`
  - 해당 능력만 단독 배치 가능
