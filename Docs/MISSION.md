# 임무 (Mission)

## 역할

- 플레이어가 턴 내 우선순위를 정해 해결해야 하는 문제 단위

## 기본 속성

- 기한(deadline)
- 인원 제한(party size cap)
- 능력 테스트 목록(다중)
- 성공 보상
- 실패 효과
- 태그(예: 괴물, 질병)

## 성공/실패

- 임무 내 모든 능력 테스트 통과 시 성공
- 기한 내 미해결 시 실패 효과 적용

## 표시 정보(UI 기준)

- 요구 능력/난이도(테스트 단위)
- 남은 기한
- 인원 제한
- 성공 보상
- 실패 효과
- 임무 태그

## UI 구조 (확정)

- 임무 UI는 `월드 UI` + `오버레이 UI` 2단 구조로 분리한다.
- 월드 UI는 임무 위치/요약 상태만 표시한다.
- 오버레이 UI는 임무 상세/배치/원정 시작 인터랙션을 처리한다.
- 원정 진행 전용 패널은 별도 범위이며, 본 스펙에서는 다루지 않는다.

## 월드 UI: 임무 카드/리스트 스펙 (확정)

### 표시 항목

- 임무명
- 남은 기한(`remainingDeadlineTurns`)
- 진행도(능력 테스트 단위)
  - 테스트별 요구 능력 아이콘 목록
  - 테스트 난이도 숫자
  - 테스트 통과 여부(아이콘+색상 강조)
- 배치 인원 표시: `배치 인원: {최대}` (최대값은 `MissionDef.partyLimit`)

### 선택/강조 규칙

- 선택 상태만 강조한다.
- 선택 기준은 `RunState.activeMissionUid`와 카드의 `mission.uid` 일치 여부다.
- 다중 선택은 허용하지 않는다.
- 카드 리스트는 `남은 기한 오름차순`으로 정렬한다(동률은 생성순 유지).

### 월드 카드 역할 제한

- 월드 카드는 요약/선택 진입용이다.
- 실제 모험가 배치/확정은 오버레이에서만 수행한다.

## 오버레이 UI: 임무 상세 스펙 (확정)

### 상단 정보

- 좌측: 임무명
- 우측: 태그 + 남은 기한 + 닫기(X)

### 본문 정보

- 좌측 영역: 능력 테스트 + 현재 파티합
  - 능력 테스트는 주사위 카드 가로열로 표시한다.
  - 카드 사이에 화살표로 테스트 순서를 표시한다.
  - 테스트 카드 숫자는 중앙, 요구 능력 아이콘은 카드 하단 바깥에 표시한다.
  - 통과한 테스트는 카드 중앙의 체크(✓)로 표시한다.
  - 현재 파티합은 힘/민첩/지능 주사위 카드 3개로 표시한다.
- 우측 영역: 배치 슬롯
  - 배치 슬롯은 2x2(총 4칸) 배열이다.
  - 빈 슬롯은 플러스(+)만 표시한다.
  - 슬롯은 모험가 초상화 표시를 전제로 정사각형으로 유지한다.
- 효과 요약 영역
  - `임무 보상` / `실패 효과`를 한 줄로 좌우 분할 배치한다.
- 액션 영역
  - `원정 시작` 버튼은 오버레이 우하단 소형 배치다.

### 효과 텍스트 포맷

- 성공 효과 라벨: `성공: {요약 텍스트}`
- 기한 실패 효과 라벨: `기한 실패: {요약 텍스트}`
- 수치 표기 규칙
  - 절대값 변화: `+N`, `-N`
  - 퍼센트 변화: `+N%`, `-N%`
  - 턴 표기: `N턴`
- 효과가 여러 개인 경우 `·` 구분자로 한 줄 요약한다.

### 배치/확정 규칙

- 현재 데이터 기준 임무 배치 상한은 `4`로 고정한다(`MissionDef.partyLimit=4`).
- 오버레이는 슬롯 상태를 기준으로 드래프트를 관리한다.
- `원정 시작`은 최소 1명 배치 시 활성화된다.
- `원정 시작` 성공 시 배치 드래프트를 커밋하고 오버레이를 닫는다.
- 오버레이는 딤 배경 없이 열리며, 열린 상태에서도 월드 상호작용은 허용한다.

### 스코프 분리

- 우측 모험가 리스트 UI는 별도 시스템이며, 본 오버레이 구현 범위에서 제외한다.
- 오버레이는 슬롯 API를 통해 외부 모험가 리스트와 연동 가능하게 유지한다.
