# 임무 (Mission)

## 역할

- 플레이어가 턴 내 우선순위를 정해 해결해야 하는 문제 단위

## 기본 속성

- 기한(deadline)
- 인원 제한(party size cap)
- 능력 테스트 목록(다중)
- 성공 보상
- 실패 효과
- 태그(예: 괴물, 질병)

## 성공/실패

- 임무 내 모든 능력 테스트 통과 시 성공
- 기한 내 미해결 시 실패 효과 적용

## 표시 정보(UI 기준)

- 요구 능력/난이도(테스트 단위)
- 남은 기한
- 인원 제한
- 성공 보상
- 실패 효과
- 임무 태그

## UI 구조 (확정)

- 임무 UI는 `월드 UI` + `오버레이 UI` 2단 구조로 분리한다.
- 월드 UI는 임무 위치/요약 상태만 표시한다.
- 오버레이 UI는 임무 상세/배치/원정 시작 인터랙션을 처리한다.
- 원정 진행 전용 패널은 별도 범위이며, 본 스펙에서는 다루지 않는다.

## 월드 UI: 임무 카드/리스트 스펙 (확정)

### 표시 항목

- 임무명
- 남은 기한(`remainingDeadlineTurns`)
- 진행도(능력 테스트 단위)
  - 테스트별 요구 능력 아이콘 목록
  - 테스트 난이도 숫자
  - 테스트 통과 여부(아이콘+색상 강조)
- 배치 인원 표시: `배치 인원: {최대}` (최대값은 `MissionDef.partyLimit`)

### 선택/강조 규칙

- 선택 상태만 강조한다.
- 선택 기준은 `RunState.activeMissionUid`와 카드의 `mission.uid` 일치 여부다.
- 다중 선택은 허용하지 않는다.
- 카드 리스트는 `남은 기한 오름차순`으로 정렬한다(동률은 생성순 유지).

### 월드 카드 역할 제한

- 월드 카드는 요약/선택 진입용이다.
- 실제 모험가 배치/확정은 오버레이에서만 수행한다.

## 오버레이 UI: 임무 상세 스펙 (확정)

### 상단 정보

- 좌측: 임무명 + 태그
- 우측 상단: 남은 기한

### 본문 정보

- 기한 실패 효과
- 성공 효과
- 테스트 상세 목록
  - 테스트별 요구 능력 합
  - 테스트별 현재 달성 상태(아이콘)
- 현재 파티 능력 합(테스트 목록 하단 1회 표시)
  - 힘 아이콘 + 합계
  - 민첩 아이콘 + 합계
  - 지능 아이콘 + 합계
  - 합계는 Modifier 반영 최종 스탯 기준으로 계산한다.

### 효과 텍스트 포맷

- 성공 효과 라벨: `성공: {요약 텍스트}`
- 기한 실패 효과 라벨: `기한 실패: {요약 텍스트}`
- 수치 표기 규칙
  - 절대값 변화: `+N`, `-N`
  - 퍼센트 변화: `+N%`, `-N%`
  - 턴 표기: `N턴`
- 효과가 여러 개인 경우 `·` 구분자로 한 줄 요약한다.

### 배치/확정 규칙

- 배치 상한은 `MissionDef.partyLimit`
- 모험가 드래그로 드래프트 배치
- 배치 불가 모험가는 비활성 상태로 표시
- 모험가 목록은 정렬된 상태를 유지
- `확정`은 최소 1명 배치 시 가능하며, 성공 시 즉시 원정 시작 상태로 전환한다.
- 원정 시작 후에는 성공/실패가 날 때까지 진행을 중단하거나 패널을 닫을 수 없다.
- 원정 시작 전 오버레이를 닫거나 다른 임무로 전환하면 드래프트 배치만 초기화한다.
