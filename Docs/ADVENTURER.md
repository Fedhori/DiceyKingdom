# 모험가 (Adventurer)

## 역할

- 임무를 수행하는 핵심 인력 유닛
- 부상/사망/피로를 관리해야 하는 장기 운영 대상

## 능력치/성장

- 능력치: 힘, 민첩, 지능
- 성장치(초안): 50%, 30%, 30%
- 임무 완료 시 경험치 획득
- 레벨업 시:
  - 플레이어가 선택한 능력치 1 증가
  - 성장치 확률 기반 추가 증가 가능
- 최대 레벨: 5
- 레벨 구간별 필요 경험치 증가

## 스탯

- 체력
  - 능력 테스트 실패 시 1 감소
  - 0이 되면 즉시 사망
  - 최대값 존재
- 기력
  - 임무 완료 시 1 감소
  - 기본값 4
  - 1: 피곤(능력치 감소)
  - 0: 탈진(임무 배치 불가)
- 영웅심
  - 능력 테스트 실패 시 체력 손실 무효 + 자동 리롤 유발 확률
  - 임무당 모험가 1회 발동 제한

## 특성

- 임무 복귀 시 랜덤 획득/교체 가능
- 긍정/부정 특성 모두 존재
- 긍정 최대 3, 부정 최대 3
- 긍정 특성 고정은 최대 2

## 장비

- 기본 장비 슬롯 2
- 착용 즉시 귀속
- 해고 전까지 해제/회수 불가

## 모집/휴식

- 모험가는 절차적으로 랜덤 생성(능력치/성장치/스탯/특성)
- 매턴 면접자 유입
- 막사 수용 범위 내에서 자유 모집
- 임무 미배치 모험가는 자동 휴식
  - 기본 휴식 효과: 체력 +1, 기력 +1
