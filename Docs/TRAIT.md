# 특성 (Trait)

## 기본 규칙

- 긍정/부정 특성으로 나뉜다.
- 임무 종료 후 랜덤 획득/교체가 가능하다.
- 긍정 최대 3개, 부정 최대 3개를 보유한다.
- 긍정 특성은 최대 2개까지 고정할 수 있다.

## 긍정 특성 아이디어(초안)

- 학생: 자신보다 레벨이 높은 모험가와 임무 시 경험치 획득량 +50%
- 무한한 체력: 임무 종료 후 30% 확률로 기력 감소 없음
- 피학증: 부상 상태면 올스탯 +1
- 빠른 회복: 체력 회복량 +1
- 아드레날린: 체력 1일 때 올스탯 +3
- 리더: 자신이 최상위 레벨(동률 허용)일 때 올스탯 +1
- 모멘텀: 앞서 성공한 테스트 수만큼 랜덤 스탯 +1(임무 한정)

## 부정 특성 아이디어(초안)

- 외톨이: 같은 임무의 다른 모험가 1명당 랜덤 스탯 -1(임무 한정)
- 엄살쟁이: 부상 상태면 올스탯 -1
- 허약: 최대 기력 -1
- 결벽증: 질병 태그 임무 진입 시 올스탯 -2
