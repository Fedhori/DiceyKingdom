# 게임 아이디어

이 문서는 확정 전 아이디어/백로그를 기록한다.
확정된 규칙은 `Docs/GAME_STRUCTURE.md`와 세부 시스템 문서를 우선한다.

## 현재 기획 축

- 장르: 인력 관리 중심 로그라이크
- 레퍼런스: 다키스트 던전, XCOM
- 차별점: 짧은 런/임무 단위 + 인력 운영 중심 재미 강화

## 핵심 목표 메모

- 주기적으로 위기를 제공해 인력 부족 압박을 만든다.
- 마지막 위기에서 고난도 도전을 집중 배치한다.
- 플레이어가 리스크를 계산하며 보상 기대값을 선택하게 만든다.

## 미확정 항목

- 스킬/소모품 상세 설계
- 경제 구조(골드 획득/소모 밸런스)
- 최종 위기 스케일링 방식
- 시설 획득 경로와 업그레이드 구조

## 아이디어 메모 템플릿

```md
- (아이디어명)
  - 의도:
  - 기대 재미:
  - 밸런스 영향:
  - 디자인 리스크:
  - 개선안:
```

## 아이디어 메모

- 모험가 출신 시스템
  - 의도: 각 모험가에게 출신(배경)을 부여해 초기 차별성과 서사 밀도를 높인다.
  - 기대 재미: 같은 스탯이라도 채용/배치 판단이 달라지고, 인력 풀이 더 개성적으로 느껴진다.
  - 밸런스 영향: 초반 채용 RNG 편차와 특정 출신 쏠림 메타가 생길 수 있다.
  - 디자인 리스크: 출신 효과가 특성/장비와 중첩되면 규칙 가독성이 급격히 나빠질 수 있다.
  - 개선안: v1에서는 출신을 1개 고정 패시브 + 태그 1개 수준으로 제한하고, 강도는 특성 1개보다 약하게 시작한다.

- 미션 구조 확장: 연계/선택/조건 미션 (BACKLOG)
  - 의도: 임무 진행 경로를 분기/게이팅해 런의 전략 깊이와 중장기 계획성을 높인다.
  - 기대 재미: 동일 런에서도 다른 공략 루트를 만들고, 파티 구성에 맞춘 임무 선택 재미를 강화한다.
  - 밸런스 영향: 선행 조건/분기 보상 설계에 따라 특정 루트가 고정 최적해가 될 수 있다.
  - 디자인 리스크: 조건 충족 여부와 분기 결과를 UI에서 명확히 전달하지 못하면 피로와 억울함이 커질 수 있다.
  - 개선안:
    - 연계 미션은 필수 선행 수를 낮게 시작하고(예: 2~3개), 대체 달성 경로를 1개 이상 제공한다.
    - 선택 미션은 분기를 2개로 제한하고, 요구 능력치/보상/실패 패널티를 같은 화면에서 비교 가능하게 노출한다.
    - 조건 미션은 \"할당 불가 사유\"를 명시 텍스트로 보여주고, 필터/정렬로 충족 가능한 모험가를 우선 표시한다.

- 추가 수주 미션 시스템 (BACKLOG)
  - 의도: 매 턴 위험-보상 선택지를 추가해 플레이어가 난이도와 리턴을 능동적으로 조절하게 한다.
  - 기대 재미: 현재 전력과 리스크 허용치에 맞춰 \"더 먹을지/안전하게 갈지\"를 선택하는 운영 재미를 만든다.
  - 밸런스 영향: 보상 기대값이 기본 루프보다 높으면 사실상 강제 선택이 되어 난이도 설계가 붕괴할 수 있다.
  - 디자인 리스크: 매 턴 제안량이 많으면 판단 피로가 커지고, 스킵 가치가 없으면 선택이 형식화된다.
  - 개선안:
    - v1은 매 턴 N개 제안 + 1회 선택 + 스킵 가능으로 고정하고, 스킵도 전략이 되도록 기본 안정 보상을 둔다.
    - 임무 난이도를 등급화(무난/위험/고위험)하고 실패 패널티를 등급에 비례해 명확히 차등한다.

- 은퇴 시스템 (BACKLOG)
  - 의도: 계륵 모험가를 손해 없이 순환시키는 출구를 제공하고, 장기 운영 시너지를 만든다.
  - 기대 재미: 해고의 손실감을 줄이면서 \"언제 전환할지\"라는 운영 의사결정을 추가한다.
  - 밸런스 영향: 은퇴 버프 누적이 과하면 후반 스노우볼이 커지고, 늦게 해금된 빌드가 급격히 약해질 수 있다.
  - 디자인 리스크: 은퇴 조건/직업/버프 종류가 많아지면 정보량이 과도해져 이해 비용이 급증한다.
  - 개선안:
    - 은퇴 직군을 소수(예: 훈련교관/상인/관리자)로 시작하고, 버프는 단순한 상시 수치형으로 제한한다.
    - 은퇴 버프는 카테고리별 상한과 점감 규칙을 둬 누적 폭주를 방지한다.

- 스킬 아이디어: 보험 (BACKLOG)
  - 의도: 핵심 순간에 실패 리스크를 완화하는 안전장치를 제공한다.
  - 기대 재미: 고난도 테스트 도전 시 \"이번엔 버틴다\"는 전술 선택을 가능하게 만든다.
  - 밸런스 영향: 쿨다운/비용이 약하면 실패 리스크 자체를 무력화해 능력 테스트 긴장감을 크게 낮출 수 있다.
  - 디자인 리스크: 무제한/저비용으로 설계되면 사실상 상시 보호막이 되어 다른 방어 수단 가치를 압도한다.
  - 개선안:
    - 턴당/임무당 사용 제한과 명확한 비용(골드/기력/소모품)을 붙여 고의적 트레이드오프를 만든다.
    - \"체력 감소 무효\"는 1회성으로 제한하고, 연속 실패 방지는 상위 버전으로 분리해 단계적으로 해금한다.
