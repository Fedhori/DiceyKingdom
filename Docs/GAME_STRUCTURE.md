# Free or Die - GAME_STRUCTURE
> 역할: 구현 기준이 되는 확정 기획/규칙/시스템 구조의 단일 기준 문서입니다.

- 버전: `v1.4`
- 마지막 갱신: `2026-02-19`
- 상태: `핵심 규칙 13차 확정 + 보상 샘플링 실패 처리 고정`

## 1) 한 줄 정체성

다크 판타지 투기장에서 살아남아 자유를 쟁취하는, 카드(AP) + 주사위(해결 방식) 하이브리드 덱빌딩 로그라이크.

## 2) 게임 개요

- 프로젝트명: `Free or Die`
- 장르: 덱빌딩 카드 로그라이크
- 테마: 중세 다크 판타지, 검투사, 투기장
- 플레이어 목표: 연속 전투를 생존하며 마지막 경기까지 도달해 자유를 얻는다.

## 3) 핵심 재미 축

- 패/코스트(AP) 기반의 우선순위 판단
- 주사위 굴림이 만드는 확률 판단과 리스크 관리
- 덱빌딩/강화/장비 선택의 장기 최적화
- 매 런마다 다른 빌드/적 조합/이벤트 조합
- 다크 판타지 투기장 분위기와 서사적 긴장감

## 4) 패배/종료 조건

- 플레이어 체력 `<= 0`: 즉시 사망, 게임 오버
- 경기 승리: 보상 단계 진입
- 런 클리어: 최종 경기 승리 시 자유 획득

## 5) 메타 게임 사이클(런 루프)

1. 경기 시작
2. 경기 종료 후 보상 화면 진입
3. 다음 경기 선택
4. 정비 시간(고정 회복, 단련)

### 5-1. 보상 화면 규칙(확정)

- 보상 화면은 슬더스와 유사한 단일 화면 흐름으로 제공
- 보상 타입:
  - 카드 보상
  - 장비(유물) 보상(해당 전투에서 발생한 경우)
- 프로토타입 범위:
  - 골드/상점/골드 보상 로직은 제외
- 카드 보상 규칙:
  - `3장 제시 -> 1장 선택` 또는 `스킵`
  - 일반/엘리트/보스 전투 모두 동일 규칙 적용
  - 보상 화면에서 카드 보상을 보류하고 다른 보상을 먼저 확인 가능
  - 카드 보상을 선택하지 않고 전체 보상을 스킵 가능
  - 단일 보상 묶음(3장) 내 중복 카드 제시는 불가
  - 중복 금지는 "해당 보상 묶음 내부"에만 적용(다른 전투 보상과의 중복은 허용)
  - fallback 로직은 사용하지 않음
  - 카드 선정 실패 시 `카드풀 0번 인덱스` 카드를 강제로 제시하고 에러 로그를 남김
- 카드 희귀도 규칙:
  - 카드 희귀도는 `일반(Common) / 고급(Uncommon) / 희귀(Rare)` 3티어 고정
  - 전투 보상 희귀도 기본 분포:
    - 기본 전투: `60 / 37 / 3`
    - 엘리트: `50 / 40 / 10`
    - 보스: `0 / 0 / 100` (희귀 3장 제시)
  - 희귀(Rare) 카드 풀은 최소 `5장` 유지(데이터 가이드라인)
  - 상점 분포(후속 도입 시 적용): `9 / 37 / 54`
  - 희귀 보정(슬더스형, 전투 보상 전역 적용):
    - 런 시작 시 `rareOffset = -5%`
    - 카드 1장이 `Common`으로 생성될 때마다 `rareOffset +1%`
    - 카드 1장이라도 `Rare`로 생성되면 `rareOffset = -5%`로 즉시 리셋(카드 선택 여부와 무관)
    - 오프셋 갱신은 "보상 1묶음(3장) 단위"로 처리:
      - Rare가 1장 이상이면 해당 보상 처리 후 `rareOffset = -5%`
      - Rare가 0장이면 해당 보상의 Common 출현 수만큼 `rareOffset` 증가(예: Common 3장 -> `+3%`)
    - 오프셋은 `Rare` 확률에만 적용하며 보정분은 `Common`에서만 차감
    - `Common`에서 차감 가능한 양을 초과하는 보정분은 무시
    - 구현식(권장):
      - `targetRare = clamp(baseRare + rareOffset, 0, 100)`
      - `if targetRare >= baseRare`
      - `  deltaUp = targetRare - baseRare`
      - `  appliedUp = min(deltaUp, baseCommon)`  // Common에서만 차감
      - `  finalRare = baseRare + appliedUp`
      - `  finalCommon = baseCommon - appliedUp`
      - `else`
      - `  deltaDown = baseRare - targetRare`
      - `  appliedDown = min(deltaDown, baseRare)` // Rare 감소분만큼 Common 증가
      - `  finalRare = baseRare - appliedDown`
      - `  finalCommon = baseCommon + appliedDown`
      - `finalUncommon = baseUncommon`
- 엘리트 유물 보상 규칙:
  - `1개 제시`
  - `수락/거절` 선택 가능
  - 거절 시 대체 보상 없음
  - 유물 중복 획득 불가

## 6) 경기(전투) 사이클

1. 턴 시작
2. 카드 드로우
3. AP 회복
4. 턴 진행(카드 사용, 주사위 획득/할당/해결)
5. 턴 종료(남은 카드/주사위 정리)
6. 적 액션 해결(남은 적 주사위로 공격, 다음 액션 선정)

### 6-1. 전투 기본 파라미터(확정)

- 기본 핸드: `5장`
- 기본 AP: `3`
- 턴 시작 시 AP는 기본값 `3`으로 회복
- 턴 종료 시 손패는 기본적으로 전부 버림
- 손패 유지(`보존`) 효과는 후속 확장(Backlog) 항목으로 보류
- 방어도는 턴 종료 시 소멸

## 7) 항복 규칙

- 사용 가능 타이밍: 플레이어 턴 시작 직후, 첫 액션 전
- 사용 제한: 이미 액션을 수행한 턴에는 불가
- 비용: 명예 `-1`
- 결과: 즉시 경기 종료, 보상 스킵
- 불가 조건:
  - 명예 `0`
  - 보스전
- 보스전에서는 항복 버튼을 비활성 처리
- 보스전 항복 비활성 사유 토스트/문구는 프로토타입 범위에서 제외(Backlog)
- 예외 카드: `무조건 항복` 카드는 액션 이후에도 항복 가능(명예 감소 동일 적용)

## 8) 플레이어 핵심 스탯

- 체력: 생존 자원, `0` 이하면 즉시 사망
- AP: 카드 사용 자원
- 골드: 상점/정비 재화(프로토타입에서는 비활성)
- 장비(유물): 슬롯 제한 없이 획득 즉시 상시 적용
- 덱: 카드 풀
- 명예: 항복 자원

## 9) 전투 핵심 규칙

### 9-1. 적

- 적은 매 턴 액션 패턴(주사위 리스트)을 제시한다.
- 예: `5, 5` / `10` / `4, 4, 4`
- 플레이어 턴 종료 시 미해결 적 주사위는 각각 굴림하며, 나온 눈만큼 플레이어에게 피해를 준다.
- 적은 고유 패시브를 가진다.

### 9-2. 카드

- 카드 사용 시 AP 소모.
- 카드가 주사위를 생성할 수 있으며, 생성된 주사위의 사용 가능 방식(격돌/방어/직접 공격)이 카드에 명시된다.

### 9-3. 주사위 사용 방식

- 격돌:
  - 내 주사위를 적 주사위에 대응시킴
  - 양측 굴림 결과 비교
  - 차이만큼 피해 발생 후 해당 주사위 해결
  - 동점일 경우 양측 주사위 모두 소멸(피해 없음)
- 방어:
  - 내 주사위를 방어로 사용
  - 굴림 결과만큼 방어도 획득
  - 획득한 방어도는 턴 종료 시 소멸
- 직접 공격:
  - 내 주사위를 적에게 직접 사용
  - 굴림 결과만큼 피해

### 9-4. 턴 종료 정리(확정)

- 플레이어가 생성했지만 사용하지 않은 주사위는 턴 종료 시 소멸

## 10) 강화 규칙

- 각 카드는 최대 `1회` 강화 가능
- 강화된 카드는 추가 강화 불가

## 11) 콘텐츠 예시 정리

### 11-1. 적 예시

- 공격 시 눈 +1, 액션 `5, 5`
- 격돌 당할 때 눈 +1, 액션 `10`
- 카드 1장 사용 시 랜덤 적 주사위 +1, 액션 `4, 4, 4`
- 소드마스터:
  - 적 주사위가 남아 있는 동안 직접 공격 불가
  - 액션 `10, 10`

### 11-2. 카드 예시(역할별 압축)

- 저비용 견제:
  - `단검 찌르기` (AP 0, 직접 공격, 주사위 4)
  - `무력화` (AP 0, 적 주사위가 없을 때만 사용 가능, 주사위 10)
- 중핵 카드:
  - `결투사` (AP 1, 격돌, 6/6)
  - `대검 휘두르기` (AP 2, 격돌/직접 공격/방어, 20)
- 조건부 리스크 카드:
  - `이판사판` (AP 2, 직접 공격, 20, 선봉, 무모)
  - `퍼포먼스` (AP 1, 격돌, 처치 시 +2골드)
- 유틸 카드:
  - `숨고르기` (AP 1, 다음 턴 AP +3)
  - `수비 자세` (AP 1, 이번 턴 직접 피해 -3)
  - `그물 던지기` (AP 1, 피해 대신 적 주사위 디버프)
- 광역/다중:
  - `휠윈드` (선택 적의 모든 주사위와 동시 격돌)
  - `비수 난사` (2/2/2/2)

### 11-3. 장비 예시

- `플레이트 아머`: 직접 공격 피해 -2
- `맞춤 신발`: 격돌 시 눈 +1
- `스멜 솔트`: 첫 턴 AP +1
- `가죽 헬멧`: 5 이상 피해를 받을 때 피해 -3
- `쿠나이`: 첫 턴 주사위 4 획득

### 11-4. 강화 예시

- 최고 주사위 x1.5
- 선택 주사위 +3
- 카드 내 모든 주사위 +1
- 카드 코스트 -1
- `승부 +4` 부여
- 모든 주사위 x2 + `소멸` 획득(소멸 없는 카드만)
- 해당 카드에 `방어` 사용 가능 플래그 추가
- `선천성` 획득(전투 시작 시 핸드 유입)

## 12) 설계 리스크(업데이트)

- 규칙 과밀 리스크:
  - `선봉`, `무모`, `소멸`, `선천성`, `승부`, `취약`이 동시에 초반에 풀리면 학습 피로가 큼.
- 확률 체감 왜곡:
  - 대형 주사위(예: 20)와 다중 소형 주사위(예: 2/2/2/2)의 기대값/분산 차이로 체감 밸런스가 흔들릴 수 있음.
- AP 0 카드 폭주:
  - 조건 완화가 겹치면 저코스트 루프가 턴 의사결정을 잠식할 가능성.
- 항복 조건 분기 리스크:
  - 보스전 판정 누락 시 항복 금지 의도가 깨질 수 있음.

## 13) 키워드 정리(v0.2)

### 13-1. 현재 사용 중 키워드

- `격돌`: 내 주사위를 적 주사위에 대응시켜 양측 굴림 결과를 비교해 해결.
- `방어`: 내 주사위를 사용해 굴림 결과만큼 방어도를 획득.
- `직접 공격`: 내 주사위를 적에게 직접 사용해 굴림 결과만큼 피해.
- `선봉`: 해당 전투에서 첫 카드로만 사용 가능.
- `무모`: 해당 턴 동안 직접 공격 이외의 주사위 사용을 제한.
- `안정 N`: 방어로 사용 시 추가 눈 보너스 `+N`.
- `취약 N`: 지정된 조건 동안 받는 피해를 증폭.
- `승부 N`: 격돌로 사용할 때 추가 눈 보너스 `+N`.
- `소멸`: 사용 후 카드가 런 중 덱에서 제거됨.
- `선천성`: 전투 시작 시 시작 핸드에 포함.
- `항복`: 명예를 소모해 전투를 즉시 종료(보상 없음).

### 13-2. 키워드 후보 상태

- `준비`, `마무리`, `약화`, `일제 격돌`, `경감`은 현재 설계에서 `불필요` 판정.
- `보존`은 프로토타입 범위에서는 제외하고 Backlog 항목으로 관리.
- 프로토타입 단계에서는 신규 키워드 추가보다 핵심 루프 완성/체감 검증을 우선한다.

## 14) 이번 루프 확정 사항

- 기본 핸드: `5장`
- 기본 AP: `3` (턴 시작 회복 기준)
- 턴 종료 손패: 기본 전부 버림(유지 효과는 추후 카드/키워드로 확장)
- 방어도: 턴 종료 시 소멸
- 미해결 적 주사위: 각각 굴림 후 나온 눈만큼 피해
- 플레이어 미사용 주사위: 턴 종료 시 소멸
- 격돌 동점: 양측 주사위 소멸
- 항복 가능 여부: 보스전 여부 + 명예/턴 상태로 런타임 검증
- 장비: 슬롯 제한 없는 유물형 상시 보유 구조로 확정
- 플레이어 시작 체력: `50` 고정
- 정비 회복: 매 경기 종료 후 `최대 체력의 40%` 고정 회복(소수점 발생 시 내림, 선택 회복은 Backlog)
- 명예: 기본 고정 상한 사용, 유물로 상한 증가 허용
- 명예 초기 상한: `2`
- 명예 상한 증가: 고정값 설계 대신 유물별 설계로 처리
- 유물 획득(엘리트):
  - `유물 1개 제시`
  - `수락/거절` 선택 가능
  - 유물 중복 획득 `불가`
  - 거절 시 대체 보상 없음
- 전투 보상(공통):
  - 카드 보상은 `3택1+스킵` 규칙 적용
  - 카드 보상 규칙은 일반/엘리트/보스 전투 동일 적용
  - 단일 카드 보상 묶음(3장) 내 중복 카드 제시는 금지
  - fallback 로직은 사용하지 않음
  - 카드 선정 실패 시 `카드풀 0번 인덱스` 강제 제시 + 에러 로그 기록
  - 카드 보상은 보상 화면에서 보류 후 재진입 가능
  - 보상 화면에서 모든 보상을 수령하지 않고 종료 가능
  - 카드 희귀도 확률:
    - 기본 전투: `60 / 37 / 3` + 희귀 보정(`rareOffset`)
    - 엘리트: `50 / 40 / 10` + 희귀 보정(`rareOffset`)
    - 보스: `0 / 0 / 100` + 희귀 보정(`rareOffset`)
- 프로토타입 제외:
  - 골드/상점/골드 보상 로직
- 스테이지 구조(프로토타입):
  - 총 5스테이지
  - 3스테이지: 엘리트 전투
  - 보스전: 1회 고정(최종 구간)
- 시작 덱:
  - 고정 시작 덱 사용
  - 저성능 기본 카드 다수 + 특색 카드 1~2장으로 구성
- 난이도 가이드:
  - 엘리트 전투는 일반 전투 대비 체감 난이도 `+50%`를 목표로 설계
- 플레이테스트 1차 성공 기준:
  - 5스테이지까지 핵심 사이클 경험 가능
  - 이를 통해 재미 여부를 정성 검증
- 프로토타입 유물 수:
  - 총 `4종`으로 시작
- 프로토타입 유물 목록:
  - `플레이트 아머`: 직접 피해 -2
  - `맞춤 신발`: 격돌 시 눈 +1
  - `스멜 솔트`: 첫 턴 AP +1
  - `가죽 헬멧`: 5 이상 피해를 받을 경우 피해 -3

## 15) 수치/밸런스 가이드라인(초안)

### 15-1. 플레이어 체력(확정)

- 시작 체력: `50`
- 설계 이유:
  - d20 계열 고변동 피해를 허용하면서도 5스테이지 러닝이 끊기지 않는 완충값
  - 항복/명예 선택이 의미를 가지되, 한 번의 고롤로 즉사하는 빈도를 낮춤

### 15-2. 코스트별 카드 파워 가이드(직접 공격 기준)

- `0코스트`:
  - 권장 기대 피해: `2 ~ 4`
  - 예시 주사위: `d4 (2.5)`, 조건부 `d6 (3.5)`
  - 가이드: 강한 부가효과가 있으면 피해를 2 근처로 낮춘다
- `1코스트`:
  - 권장 기대 피해: `5 ~ 8`
  - 예시 주사위: `d10 (5.5)`, `d12 (6.5)`, `2d6 (7.0)`
  - 가이드: 범용 핵심 카드 구간, 조건 없는 표준 카드의 중심축
- `2코스트`:
  - 권장 기대 피해: `9 ~ 13`
  - 예시 주사위: `d18 (9.5)`, `d20 (10.5)`, `2d10 (11.0)`
  - 가이드: 고효율/고변동/강한 유틸 동반 카드 구간

### 15-3. 가이드 해석 원칙

- 고정 규칙이 아니라 "디자인 보조선"으로 사용
- 아래 요소가 붙으면 기대 피해를 조정한다:
  - 상향 요인: 강한 조건, 무모/소멸 같은 페널티, 선봉 제약
  - 하향 요인: 다중 모드 허용(격돌+방어+직공), 즉시 이득(AP 회복 등), 광역 처리
- 목표:
  - 같은 코스트 내 카드 역할이 겹치지 않게 차별화
  - 평균 기대치보다 "사용 상황"에서 가치가 갈리도록 설계

## 16) 개선 제안(후속 검토용)

1. 항복 로직 단순화
   - 데이터 변수 없이 `isBossStage`만으로 항복 불가 처리
   - 조건식: `!isBossStage && honor > 0 && turnStart && !hasTakenAction`
2. 엘리트 보상 테이블 분리
   - 일반 전투와 엘리트 전투 보상을 분리해 유물 경제를 독립 관리
3. 프로토타입 유물 4종 제안
   - `플레이트 아머`: 직접 피해 -2
   - `맞춤 신발`: 격돌 시 눈 +1
   - `스멜 솔트`: 첫 턴 AP +1
   - `가죽 헬멧`: 5 이상 피해를 받을 경우 피해 -3

## 17) 최종 목표(현재)

- 목표: `5스테이지`까지 구현된 프로토타입 제작 후 플레이테스트
- 산출물 기준:
  - 플레이 가능 런 루프(전투/보상/선택/정비)
  - 항복/명예/유물/강화 핵심 시스템 동작
  - 테스트 가능한 난이도 곡선(5스테이지)
