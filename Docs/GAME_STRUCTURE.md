# GAME_STRUCTURE
> 역할: 구현 기준이 되는 확정 기획/규칙/시스템 구조의 단일 기준 문서입니다.

- 버전: `v0.1`
- 마지막 갱신: `2026-02-21`
- 상태: `초안(확정 룰 반영)`

> 용어 단일 기준: `Docs/GLOSSARY.md`

## 1) 한 줄 정체성

중세 다크 판타지 왕국 방어 덱빌딩 로그라이크.  
플레이어는 **왕**으로서, 공개된 **Enemy Intent**를 보고 3개의 **Battlefield**에 병력 주사위를 분산 배치하여 **Combat Strength** 싸움에서 승리한다.

## 2) 게임 개요

- 프로젝트명: `미정(TBD)`
- 장르: 덱빌딩 로그라이크 *(드로우 없는 “편성형 Roster Deck” 방식)*
- 테마: 중세 다크 판타지
- 플레이어 역할/목표:
  - 플레이어는 왕국을 수호하는 왕이며, **전투에서 패배하면 즉시 런이 종료(게임 오버)** 된다. 필요 시 **안정도(Stability)** 를 소모해 후퇴하여 전투를 회피할 수 있다.

## 3) 핵심 재미(의사결정 포인트)

- **분배 고민**: 적의 의도(Enemy Intent)를 보고, 한정된 병력을 어떤 전장에 투입할지 결정한다.
- **편성 고민**: 보급품 한도(Supply Limit) 안에서 어떤 `Squad/Support`를 들고 갈지 결정한다.
- **전략 다양성**: 매 런마다 다른 조합/스킬 운용으로 다양한 전략을 시도한다.

## 4) 게임 오버 / 패배 규칙

- 게임 오버 조건: **전투 패배(플레이어 Morale ≤ 0)**

- 전투 패배(Defeat):
  - 전투 중 플레이어의 사기(Morale)가 0 이하가 되면 전투가 종료되고, **즉시 런이 종료**된다.

- 후퇴(Retreat):
  - 아군 배치 단계(Player Deploy Phase)에서 사용 가능 (보스전 불가)
  - 사용 조건(확정): **Stability > 0** 일 때만 가능  
    - Stability가 `0 이하`라면 후퇴 버튼/행동은 비활성화된다.
  - 후퇴 시: 보상 없이 전투 종료 + **Stability -1**


## 5) 런 게임 사이클(메타)

1. **전투 단계(Battle)**
2. **보상 단계(Reward Phase)**  
   - 카드(스쿼드/서포트) 보상, 골드 등
3. **정비 단계(Maintenance Phase)**  
   - 보급품 한도에 맞춰 덱(편성) 구성
   - 예비 편성(Reserves)에 카드를 보관/교체 가능

> 참고: 상점/이벤트/유물/강화/소모품은 프로토타입 범위 밖.

## 6) 전투 구조

### 6.1 전투 시작(1회): Battle Start Triggers

- 덱(편성)에 포함된 모든 카드가 전투 시작 시 **1회씩 트리거**된다.
- 트리거 우선순위(확정):
  1) `Squad` 전부 트리거 → 병력(Troop) 소환/준비  
  2) `Support` 전부 트리거 → 병력/규칙 보정(버프 등)

- 같은 타입 내부 트리거 순서(확정): **덱(편성) 배열 순서대로** 처리한다.
  - 즉, 덱 리스트가 곧 트리거 실행 순서다.

### 6.2 전장(Battlefield)

- 프로토타입 확정: 전투당 전장은 **3개**.
- 프로토타입 확정: 전투 중 전장은 **턴마다 바뀌지 않고 고정**된다.
- 배치 제한(Slot Limit): **기본 무제한**.
  - 전장 데이터에 제한이 명시된 경우에만 적용한다.
  - 배치/이동으로 제한을 **초과할 수 없으며**, 초과하는 행동은 불가능하다(UI에서 선택 불가 처리).
- 각 전장은 결과별 효과를 가진다:
  - `Great Victory / Victory / Draw / Defeat / Great Defeat` 조건별 효과/피해가 존재

### 6.3 턴(반복) 단계

1) **회수 단계(Recall Phase)**  
- 전장에 배치돼 있던 모든 병력이 **Camp로 복귀**한다.

2) **적 배치 단계(Enemy Deploy Phase)**  
- 적이 병력을 각 전장에 배치한다.  
- 프로토타입 확정: Enemy Intent는 **완전 공개**.

3) **아군 배치 단계(Player Deploy Phase)**  
- 플레이어가 Camp의 병력을 전장에 분배 배치한다.
- 배치 제한(Slot Limit)은 기본 무제한이며, 전장에 제한이 명시된 경우에만 해당 전장에 적용한다.
  - 제한을 초과하는 배치/이동은 불가능하다.
- 이 단계에서 후퇴(Retreat) 가능(보스전 제외).

4) **굴림 단계(Roll Phase)**  
- 전장에 배치된 병력들이 주사위를 굴린다.
- 각 병력의 눈(Face Value)과 전장별 Combat Strength가 표기된다.

5) **조정 단계(Tactics Phase)**  
- 스킬 등으로 전장에 영향을 준다(이동, 눈 보정 등).
- 확정 룰: “수치 증가”는 기본적으로 **눈 변화**이며, UI에서 즉시 반영돼야 한다.

6) **판정 단계(Resolve Phase)**  
- 전장을 **하나씩 순서대로** 판정(Resolve)한다.
  - 순서(확정): 전장 리스트의 고정 순서(예: UI 좌→우 / index 0→1→2)
  - 각 전장 판정마다: `결과 확정 → 효과/피해 적용 → 양측 Morale 즉시 체크`
  - 어느 시점이든 한쪽 Morale ≤ 0 이 되면 **즉시 전투 종료**(남은 전장은 판정하지 않음).

## 7) 전투 수치/판정 규칙(확정)

### 7.1 병력(Troop) 기본 스펙

- 병력은 주사위 1개로 표현한다.
- 병력은 다음을 가진다:
  - `Power` (예: Power 4 = d4)
  - `눈(Face Value)` (굴림 결과, 최소 1 / 상한 없음)
  - 고유 효과(조건부 보정 등)

### 7.2 눈(Face Value) 보정 규칙

- 최솟값: 1
- 최댓값: 없음(상한 없음)
- 별도 명시가 없다면 수치 변화는 **눈 변화**로 해석한다.

### 7.3 Combat Strength 계산

- 전장 Combat Strength =  
  `해당 전장에 배치된 병력들의 최종 눈 합` + `전장/스킬이 부여한 전장 단위 보정(예: +2)`
- 단순 합(확정)

### 7.4 Great Victory 판정

- Great Victory 조건(확정):  
  `승자 Combat Strength >= 패자 Combat Strength * 2`
- Great Defeat는 위 조건의 반대 결과로 사용한다.

### 7.5 이동(재배치/유인책) 시 굴림값 유지(확정)

- 굴림이 끝난 병력을 다른 전장으로 이동시키면, 해당 병력의 **현재 눈(Face Value)은 유지**된다.

### 7.6 증원(Reinforce) 효과 해석(확정)

- “증원: 전장 하나의 아군 Combat Strength +2”
  - 전장 단위 합산값에 +2를 더한다.
  - **병력의 눈(Face Value)은 변하지 않는다.**

## 8) 리소스 규칙(확정)

### 8.1 사기(Morale)

- 전투에서의 체력.
- 0 이하가 되면 전투 종료.

### 8.2 안정도(Stability)

- 런 단위 자원.
- 역할(확정): **후퇴(Retreat)에 사용되는 자원**이다.
- 규칙(확정):
  - 후퇴 시 Stability `-1` (단, 결과는 **최소 0으로 clamp**)
  - Stability가 `0 이하`라면 **후퇴 불가**(게임 오버 조건 아님)


### 8.3 보급품(Supply)

- 보급품 한도(Supply Limit): 전투에 들고 갈 수 있는 덱(편성)의 총 비용 상한.
- 보급품은 전투 중 소모 자원이 아니다(확정).

### 8.4 마나(Mana)

- 최대 마나: `5`
- 전투 시작 시: `mana = manaMax` (최대치로 충전)
- 턴 회복: 매 턴 `+2`
- 스킬 사용 시 소진된다.
- 쿨다운 감소: **턴 종료 시 -1**(확정)

## 9) 프로토타입용 콘텐츠(초기)

> 상세 스펙은 `Docs/IDEA_BANK.md`(아이디어 원문/정리)와 동기화한다.

### 9.1 Squad(카드 타입) 예시

- 예비대 (Supply Cost 1): 예비군×2
- 미코 암살부대 (Supply Cost 1): 미코 암살자×1
- 드워프 포병단 (Supply Cost 3): 드워프 대포×2
- 랫킨즈 (Supply Cost 1): 랫킨×3

### 9.2 Troop 예시

- 예비군 (Power 2): 턴 종료 시 미배치 상태였다면, **다음 굴림에 적용되는 눈 보정 +2**를 누적(스택)
- 미코 암살자 (Power 4): 해당 전장에 할당된 적이 하나뿐일 경우, 눈 ×2
- 드워프 대포 (Power 4): 전장의 적들의 눈 -1 (최소 1)
- 랫킨 (Power 2): (효과 없음)

### 9.3 Skill 예시

- 재배치(Redeploy): 마나 2, 쿨다운 2, 조정 단계, 아군 병력 1개를 다른 전장으로 이동(눈 유지)
- 유인책(Decoy): 마나 2, 쿨다운 2, 배치 단계, 적 병력 1개를 다른 전장으로 이동
- 위험한 접근(Risky Approach): 마나 1, 쿨다운 1, 배치 단계, **(플레이어만)** Victory를 Great Victory로 승격
- 안전한 접근(Safe Approach): 마나 1, 쿨다운 1, 배치 단계, **(플레이어만)** Great Victory를 Victory로 하향
- 증원(Reinforce): 마나 2, 쿨다운 2, 조정 단계, 전장 하나의 아군 Combat Strength +2

## 10) 프로토타입 범위(확정)

- 구현 목표(프로토타입):
  - 3개 전장 고정 전투 루프
  - Squad/Support 전투 시작 트리거
  - Enemy Intent 공개
  - 주사위 굴림/눈 보정/Combat Strength 계산
  - 스킬(마나/쿨다운) 사용
  - 승패 판정 및 전장 결과별 효과 발동
- 미구현(범위 밖):
  - 유물, 강화, 소모품
  - 상점/이벤트
  - 매 턴 전장 랜덤 교체
