# 게임 구조

이 문서는 **Wage Slave Simulator (사축 시뮬레이터)**의 게임 컨셉, 핵심 루프, 용어, 프로토타입 구현 범위를 정의한다.

- 마지막 갱신: **2026-02-18**
- Unity 버전: **Unity 6.2 (6000.2.x)**
- 장르: **덱빌딩 카드 로그라이크**
- 테마: **사이버펑크 / 디스토피아 / 다크 코미디**

## 프로젝트 목표

- 플레이어가 제한된 자원(시간/건강/기력/내성/신용/돈)으로 최적 의사결정을 반복하게 만든다.
- "무엇을 먼저 처리할지"에 대한 우선순위 판단을 핵심 재미로 둔다.
- 매 런마다 덱 시너지 실험이 가능하도록 로그라이크 변주 폭을 확보한다.
- 회사 생활 공감 소재를 다크 코미디 톤으로 전달한다.

## 핵심 루프

1. 스테이지 시작
2. 주요 상황 + 서브 상황 배치
3. 카드 사용/퇴근/기타 액션으로 상황 처리
4. 주요 상황 전부 해결 시 스테이지 클리어
5. 보상 수령
6. 다음 스테이지 진입 (주기적으로 상점 포함)

## 용어 사전(확정)

- `상황`: 스테이지 내 해결 대상. `기한`과 `작업량`을 가질 수 있다.
- `주요 상황`: 기한 내 미해결 시 즉시 게임 오버를 유발하는 필수 목표.
- `서브 상황`: 추가 보상용 선택 목표. 위험을 감수하고 선처리할 수 있다.
- `기한`: 시간 경과에 따라 감소하는 남은 유효 시간.
- `작업량`: 카드 효과로 깎아 0 이하가 되면 해결되는 수치.
- `시간`: 액션/카드 사용에 소비되는 핵심 자원. 시간 소비 시 모든 기한이 감소한다.
- `퇴근`: 시간을 소모해 회복/핸드 리셋을 수행하는 휴식 액션.
- `질병`: 불이익 중심의 카드군(슬더스 저주 포지션).
- `물건`: 영구 효과 아이템(슬더스 유물 포지션).
- `아이템`: 전투 중 소모형 보조 아이템(슬더스 포션 포지션).
- `임플란트`: 부위 장착형 영구 개조 시스템.

## 플레이어 스탯/재화

- `건강`: 신체적 체력.
- `기력`: 정신적 체력.
- `내성`: 약물 저항 수치. 약물 섭취 시 감소.
- `신용`: 범죄 저항 수치. 불법 행위 시 감소.
- `돈`: 상점/이벤트 지불 자원.

## 시스템 명세 초안

### 상황 시스템

- 상황은 `기한`, `작업량`, `지속 효과`를 조합해 구성한다.
- `기한만 있는 상황`: 기한 만료로 사라짐(대체로 페널티 유발).
- `작업량만 있는 상황`: 작업량 0 이하가 되어야 제거.
- `기한+작업량 상황`: 기한 내에 작업량을 처리해야 안전.
- 주요 상황 미해결(기한 만료)은 즉시 게임 오버.

### 시간 시스템

- 카드 사용/특정 액션은 시간 비용을 갖는다.
- 시간이 줄 때마다 기한이 있는 모든 상황의 기한이 함께 감소한다.
- 시간은 사실상 "턴 수 + 실패 카운트다운" 역할을 동시에 수행한다.

### 퇴근 시스템

- 플레이어가 임의 시점에 선택 가능.
- 고정 시간 소모 후 `건강/기력 회복`, `내성 회복`, `핸드/드로우 리셋`.
- `신용`은 스테이지 전환 시에만 초기화.

### 카드/덱 시스템

- 카드 사용 조건: 카드가 요구하는 스탯/재화 비용을 만족해야 사용 가능.
- 카드 효과는 `작업량 처리`, `자원 변동`, `상황 조작`, `위험 감수 보상` 중심.
- 질병 카드는 덱 오염 장치로 사용.
- 상점/보상에서 카드 획득, 상점에서 카드 제거 가능.

### 임플란트/물건/아이템

- 임플란트: 부위별 장착 제한 + 강한 지속효과 + 잠재적 부작용(질병 유입).
- 물건: 런 전반 규칙을 바꾸는 영구 패시브.
- 아이템: 즉시 위기 대응용 소모 자원(세부 효과 미확정).

## 카드/상황 샘플 메모

- 본 문서의 카드/질병/임플란트/물건/상황 예시는 **초안**이다.
- 확정 전까지는 "짧은 텍스트, 단일 핵심 효과, 명확한 트레이드오프"를 우선한다.
- `무제한 사용 + 저비용 + 큰 이득` 패턴은 고위험으로 분류한다.

## 아이디어 리뷰 (초안 기준)

[아이디어 요약]
- 시간 압박형 카드 로그라이크에 회사 생활 리소스 관리(건강/기력/내성/신용)를 결합한 구조.

[좋은 점]
- 시간과 주요 상황의 결합이 목표 집중도를 강하게 만든다.
- 퇴근 액션이 "회복 vs 시간 손실"의 명확한 딜레마를 제공한다.
- 다크 코미디 소재가 시스템 스트레스와 테마를 일치시킨다.

[나쁜 점]
- 자원 축이 많아 초반 학습 부담이 높다(건강/기력/내성/신용/돈/시간).
- "기한 + 작업량 + 지속 디버프"가 겹치면 판단 피로가 급증할 수 있다.
- 일부 카드가 수치상 과격해 보이며(예: 고효율 작업량 카드), 밸런스 붕괴 위험이 있다.

[놓친 점]
- 패/드로우 규칙(턴당 드로우 수, 핸드 제한, 턴 종료 조건)이 미정이다.
- 스테이지 길이 기준(목표 시간 예산, 상황 수, 주요/서브 비율)이 미정이다.
- 실패 복구 장치(주요 상황 직전 구제 수단) 유무가 미정이다.

[질문]
1. 1스테이지 기준 기본 핸드 규칙(초기 핸드 수, 턴당 드로우, 핸드 제한)은 어떻게 고정할지?
2. 주요 상황은 1개 고정인지, 2개 이상 동시 배치도 허용할지?
3. 퇴근 1회당 시간 소모량은 고정값인지, 상황/효과에 따라 가변인지?
4. `건강`과 카드 텍스트의 `체력` 용어를 하나로 통일할지?
5. 신용/내성 0 이하 도달 시 즉시 패배가 있는지, 아니면 패널티만 있는지?

[디자인 리스크]
- 초반: 자원 종류 과다로 카드 읽기-의사결정 시간이 길어질 위험.
- 중반: 시간 증가/감소, 기한 증가/감소가 누적되면 최적해 탐색이 과도해질 위험.
- 후반: 특정 조합(시간 조작 + 고효율 작업 카드)이 메타를 단일화할 위험.

[개선 제안]
1. 프로토타입에서는 자원 축을 `건강/기력/시간/돈` 중심으로 먼저 잠그고, 내성/신용은 약식 규칙으로 축소 도입.
2. 카드 텍스트 길이를 1줄 규칙으로 제한하고, 복합 카드(예: 강박)는 후순위로 이동.
3. 주요 상황 실패 직전 1회성 완충 장치(예: 긴급 연장 이벤트) 여부를 실험해 좌절 곡선을 조정.

[결론]
- 판정: `조건부 채택`
- 조건 또는 사유: 프로토타입 단계에서 자원/규칙 복잡도를 의도적으로 줄여 핵심 재미(시간 압박 + 우선순위 판단) 검증을 우선해야 함.

## 1스테이지 프로토타입 범위 (v0.1)

- 목표: `A사와의 계약문서 작성(주요 상황)`을 기한 내 해결.
- 스테이지 구성:
  - 주요 상황 1개 고정.
  - 서브 상황은 샘플 풀에서 랜덤 배치.
  - 플레이어는 카드 사용 + 퇴근으로 자원과 기한을 관리.
- 클리어 조건: 주요 상황 전부 해결.
- 게임 오버 조건: 주요 상황 미해결(기한 만료).

## 프로토타입 구현 우선순위

1. `P0 - 핵심 도메인 모델 고정`
   - `RunState` 확장: 건강/기력/내성/신용/돈/시간, 상황 리스트, 덱/패/버림/소멸.
   - 검증: 빈 UI에서도 1턴 진행 시 시간/기한/작업량 변화가 일관되게 반영.
   - 리버스 플랜: 스탯 6종을 `Health/Energy/Time/Money` 4종으로 즉시 축소 가능하도록 분리 구현.
2. `P0 - 상황/시간 해석기 구현`
   - 기한 감소, 작업량 감소, 주요 상황 판정, 스테이지 종료 판정.
   - 검증: 자동 시뮬레이션 100회에서 판정 오류(음수 기한/중복 종료) 0건.
   - 리버스 플랜: 효과형 상황을 비활성화하고 기한+작업량만 남겨 최소 루프 유지.
3. `P0 - 카드 실행 파이프라인`
   - 카드 비용 체크 -> 적용 -> 시간 차감 -> 상황 갱신 순서 고정.
   - 검증: 카드 5종(작업/집중작업/명상/야근/퇴근) 기준 스냅샷 테스트.
   - 리버스 플랜: 복합 카드/랜덤 타격 카드 제외, 단일 타깃 카드만 유지.
4. `P1 - 덱/드로우/퇴근 루프`
   - 드로우, 버림, 질병 발동, 퇴근 시 핸드 리셋 처리.
   - 검증: 퇴근 전후 핸드/스탯/시간 일관성 확인.
   - 리버스 플랜: 질병 발동을 "드로우 시 즉시 효과 1회" 단순 규칙으로 통합.
5. `P1 - 기본 UI(디버그 친화형)`
   - 상황 패널(기한/작업량), 자원 바, 핸드 카드 버튼, 로그 뷰.
   - 검증: 1스테이지 수동 플레이가 UI만으로 가능해야 함.
   - 리버스 플랜: 카드 연출 제거, 텍스트 버튼 중심 UI로 축소.
6. `P2 - 컨텐츠 확장 1차`
   - 카드/상황 샘플 추가, 상점 1종, 보상 선택 1종.
   - 검증: 1런 10회 플레이에서 클리어율/패배 원인 분포 수집.
   - 리버스 플랜: 상점 제거 후 스테이지 보상만 유지.
