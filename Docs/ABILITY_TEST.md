# 능력 테스트 (Ability Test)

## 구성

- 요구 능력: 1개 이상의 능력치 조합(예: 힘+민첩)
- 난이도: 테스트 상대 강도

## 계산 단위

- 임무 배치 모험가들의 요구 능력 합을 모험가 측 값으로 사용

## 판정 흐름

1. 모험가 측과 난이도 측이 각각 1~N 범위에서 롤한다.
2. 모험가 롤이 상대와 같거나 크면 성공한다.
3. 성공 시 다음 테스트로 진행한다.
4. 실패 시 해당 임무 배치 모험가 중 무작위 1명이 체력 1을 잃는다.
5. 실패해도 재시도 가능하다.

## 실패 중 부가 규칙

- 모험가 체력이 0이 되면 즉시 사망한다.
- 사망한 모험가 없이 임무를 계속 진행한다.
- 각 테스트에는 포기하기가 있으며, 성공 보상을 포기하고 임무를 중단할 수 있다.

## 영웅심 규칙

- 실패 시 모험가별 영웅심 테스트를 내부 수행한다.
- 한 명이라도 성공하면 해당 실패에서 체력 손실이 발생하지 않는다.
- 영웅심 테스트 기회는 모험가당 임무당 1회다.
